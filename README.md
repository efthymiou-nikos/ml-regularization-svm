# Regularization & SVM Classification

**Hellenic Open University | MSc Data Science & Machine Learning | 2024–2026**

---

## Overview  
This project explores two supervised machine learning problems focusing on regularization techniques for regression and kernel methods for classification.

---

## Problem 1 — Housing Price Prediction (Ridge & Lasso Regression)

- **Dataset:** California Housing (scikit-learn)  
- **Goal:** Predict median house values using regularized regression models  
- **Techniques:** Linear Regression, Ridge Regression, Lasso Regression, GridSearchCV for optimal alpha  
- **Evaluation:** MSE, RMSE, R² on test set  
- **Key Insight:** Comparison of regularization effects on model coefficients and overall performance  

---

## Problem 2 — Banknote Authentication (SVM Classification)

- **Dataset:** Banknote Authentication (UCI)  
- **Goal:** Classify banknotes as genuine or counterfeit  
- **Techniques:** Linear SVM, RBF SVM, decision boundary visualization, kernel density estimation (KDE)  
- **Evaluation:** F1-score, classification report, cross-validation  
- **Key Insight:** Effect of C and gamma parameters on margin width, decision boundaries, and model complexity
