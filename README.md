# Regularization & SVM Classification

**Hellenic Open University | MSc Data Science & Machine Learning | 2024-26**

---

## Overview
Two machine learning problems exploring regularization techniques for regression 
and kernel methods for classification.

## Problem 1 — Housing Price Prediction (Ridge & Lasso Regression)
- Dataset: California Housing (sklearn)
- Goal: Predict median house values using regularized regression models
- Techniques: Linear, Ridge and Lasso Regression, GridSearchCV for optimal alpha
- Evaluation: MSE, RMSE, R² on test set
- Key insight: Comparison of regularization effects on model coefficients and performance

## Problem 2 — Banknote Authentication (SVM Classification)
- Dataset: Banknote Authentication (UCI)
- Goal: Classify genuine vs counterfeit banknotes
- Techniques: Linear SVM, RBF SVM, decision boundary visualization, KDE plots
- Evaluation: F1-score, classification report, cross-validation
- Key insight: Effect of C and gamma parameters on margin width and model complexity

## Tools & Libraries
Python · scikit-learn · pandas · matplotlib · seaborn · numpy
